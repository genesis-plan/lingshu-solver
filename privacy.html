隐私与安全说明

生效日期：2026-09-01 ｜ 适用范围：hongchenlingjing.com 上的灵数求解器网站（在线求解器）及其远程调用端点（/mcp）。

一句话结论

本工具是纯数学方程求解器：你的方程在浏览器本地计算，不经过网络上传；系统不收集、不存储任何个人信息。

二、服务器留存的最低限度日志（安全运维必需）

  • 网站访问日志（nginx）：记录访问者的 IP 地址、访问时间、访问的 URL。不含你输入的任何内容（网页端方程不上传，无从记录）。日志定期滚动清理。
  • MCP 调用日志（仅远程 AI Agent 调用 /mcp 端点时）：记录调用时间、来源 IP、调用的工具名、耗时、结果类型等元数据，不记录方程内容与求解结果。日志超过 5MB 自动滚动。
  • 反馈日志（仅当主动调用反馈接口时）：反馈文本仅留存于服务器本地、不向任何第三方传输；落盘前自动隐去其中疑似手机号 / 证件号 / 邮箱 / 超长数字串。

以上日志仅用于安全审计与服务可用性保障，不用于用户画像、不用于营销、不对外提供。

三、你的计算结果谁能看到

  • 网页端：方程与结果只在你自己的浏览器里显示和计算，其他任何访问者都看不到。
  • 本站没有分享、评论、排行榜等任何公开展示用户内容的功能，也没有论坛 / 社区板块（不具舆论属性与社会动员能力）。
  • MCP 远程调用：求解结果仅通过应答返回给发起该次调用的客户端，不做任何缓存共享或公开发布。

四、输出内容边界

  • 输出仅为数学结果（数字、变量名、诊断文字），不生成图片、不生成正文文章类内容。
  • 结果页面所有内容经过转义处理，防止脚本注入（XSS）。

五、防攻击措施

  • 传输加密：全站 HTTPS（TLS 1.2+）。
  • 输入防护：方程文本长度上限（100KB）、数量上限（64 条）、变量上限（6 个）；入口自动拦截非数学的自然语言文字。
  • 服务防护：请求体大小上限、每 IP 请求频率限制、会话超时自动清理、日志自动轮转。
  • 响应加固：Content-Security-Policy、X-Frame-Options（禁止被嵌入第三方页面）、X-Content-Type-Options、Referrer-Policy、Permissions-Policy（禁用摄像头 / 麦克风 / 定位等浏览器能力）。

  • 本站为纯工具类计算服务，不含用户生成内容的公开发布功能，不具舆论属性或社会动员能力。
