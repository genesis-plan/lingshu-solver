# 灵数超越路线：为什么能赢 Mathematica，而不必追平它

> 2026-10-02 · 基于实查（Wolfram 官方发布说明 + Richardson 定理 / Risch 算法文献）
> 结论先行：**不追功能广度（永远追不上 38 年、6000+ 函数库），改打「结果可信度」——旧霸主结构上做不到的事。**

---

## 一、突破口：他们给答案，我们给「答案 + 证明」

### 1.1 旧霸主的根本缺陷是**理论性**的，不是工程性的

**Richardson 定理**（决定性依据）：
- 结构 $(R,+,\times,\exp,\sin)$ 的**零等价问题不可判定**。
- 因此 **CAS（含 Mathematica、Maple）在涉及 sin/exp 的表达式相等性上，不存在通用判定算法**。
- CAS 只能靠**启发式**：模式匹配改写规则、Taylor 展开、随机多点数值抽查。
- 官方与文献一致承认：这些启发式**会带来表达式膨胀，或给出错误化简**。

**Risch 算法的现状**（决定性证据）：
- 对一般初等函数，Risch **不是算法而是半算法**——它需要判定"某表达式是否恒为零"（常数问题）。
- **不存在完整实现**；所有 CAS 都在此处退化为启发式。
- 一旦把绝对值加入初等函数，**已知不存在这样的算法**。

**H10（Matiyasevich 1970）**：丢番图方程可解性不可判定 ⇒ CAS 的符号求解器只能覆盖线性/二次等特例，更一般的情形必须**退回启发式或数值**。

**推论（这是灵数的立足点）**：
> 旧霸主**在结构上就无法保证**一个答案正确；它们只能"尽力给答案 + 承认可能错"。
> 而灵数走**区间算术 + 认证**路线：每个解都带**数学上严格的误差界**，证不出就**明说证不出**。
> **这不是"更好的 Mathematica"，是它做不到的那一类东西。**

### 1.2 他们的战略方向也不是"可证"

Wolfram Language / Mathematica 15（2026-06-16 发布，38 年来最大升级）的实际投入：
- 内置 AI Assistant（自然语言 → Wolfram 代码）
- **Wolfram Agent Tools**（让 Claude Code / Codex 调用本地 Wolfram 内核）
- **MCP 框架**（让外部 AI 客户端直连 Wolfram 计算能力）
- 符号音乐系统、GB 级笔记本、ModelFit、DSolve + AI 兜底
- 修 2,422 个 bug（含 `SolarEclipse["LunarNode"]` 算错、`WeberE` 大参数给错值、`Together` 带 Modulus 出错）

**读出来的信号**：Wolfram 的答案是"更大 + 更全 + 接入 AI"，**不是"更确定"**。他们把 LLM 当成增强（DSolve 卡住时让 AI 找路径），而不是当验证器。

**这恰好留出了一个他们不占的位子：确定性、可审计、零依赖、可嵌入 AI 的可信计算内核。**

## 三、超越路线（按 ROI 排序）

### P0 · 把 `provenIsComplete` 从"预算内没漏"升级为"数学上证明没漏"
**这是与 CAS 的分水岭。** CAS 给一个解集，从不告诉你"这就是全部"。

手段（可判定子类才可能，Richardson 定理划定了边界）：
- **Sturm 序列**：一元多项式实根**精确计数 + 区间隔离**（Sturm 1829，根隔离的古典算法）。⇒ 一元多项式可达"数学上证明完备"。
- **消元/结式（resultant）**：把 n 元系统降为低元，逐层计数 ⇒ 多元多项式可给出"实解总数"这个**精确数字**。
- 对含超越函数的系统：**明确宣告"完备性不可判定"并给出理由**（引用 Richardson），而不是假装完备。

**为什么 CAS 做不到**：它们不计算证明，只返回结果。

### P1 · 同伦延拓（Bertini 定理：概率 1 穷尽全部孤立解）
把"启发式多起点牛顿"升级为"理论上保证不漏孤立根"。这是从"找得到一些"到"找齐全部"的质变。

### P2 · 区间紧化（直线线程序 + 多变量 Horner）
Breiding–Rose–Timme（TOMS 2023）明确指出：区间 overestimate 随直线线程序变长而增长，自动应用多变量 Horner 可压低，**报告区间宽度改善 25%**。直接提升全部认证器的成功率。

### P3 · 认证的更高阶
- **deflation**（Leykin–Verschelde–Zhao 2006/2008）：治重根/奇点导致认证失败
- **Shub–Smale α 理论**（TOMS Algorithm 921）：给出 $\|x-z\|\le 2\beta$ 严格界（**已落地**）
- 自适应精度 / multiprecision

### P4 · 不可判定性的诚实产品化
**把 Richardson 定理做成卖点**：对超越系统，灵数会明确说"这里存在不可判定性，完备性无法保证，但已找到的解带严格误差界"。CAS 只会静默返回一个可能错的答案。
**能证明不可判定，比假装能算更值钱。**
