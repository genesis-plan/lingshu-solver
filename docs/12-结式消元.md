# suan59：结式消元（Resultant Elimination）— 二元与三元多项式系统的闭式完备路径

> 落地日期：2026-10-03
> 定位：**剪枝之外的第三条路**。剪枝受根密度下界限制，采样+牛顿不完备；结式消元把多元问题**精确降维**为一元多项式，交给已有的闭式求根 + Sturm 精确计数。

---

## 一、为什么需要它（实测缺口，不是猜测）

2026-10-03 能力全景扫描（26 题）暴露：**灵数完全没有多元消元工具**。

```
resultant      无        sylvester     无
polynomialGCD  无        gcdPoly       无
```

⇒ 多元只能启发式求解，**完备性无上界**。这正是 Mathematica `Reduce` / SymPy `solve` 靠的东西。
对测实据：二元恰定系统 `x²+y²=4, xy=1` 走多起点牛顿 12.9ms；三元 9 点 Bézout 系统走多起点牛顿 **265ms**。

## 二、数学链条

### 二元（一次结式）
```
f(x,y)=0, g(x,y)=0
  → Res_y(f,g) = R(x)                    Sylvester 结式 / PRS 伪余式链
  → Sturm 序列精确计数 R 在声明域内的实根个数   ← 完备性证明
  → polynomialAllRoots(R) 得全部 x 候选
  → 固定 x，把 f、g 变成 y 的一元多项式 ⇒ 求 y 根
  → 每个 (x,y) 回代【两个原方程】，残差 > 1e-6 即丢弃（去伪根）
```

### 三元（字典序两次结式）
```
f(x,y,z)=0, g(x,y,z)=0, h(x,y,z)=0

【主消元对象的选择】必须挑【含 z 的方程】做主消元 —— 否则
  Res_z(f,g) = f^deg(g)·g^deg(f)（退化乘积），解集会被算错。
  实证：x³−3x=y, y³−3y=x, z=x+y 真解 9 个，误选会漏掉全部 9 个。

  → Res_z(主, 辅) = R(x,y)
  → Res_z(第三, 主) = H(x,y)   （第三式不含 z 时直接取其 z⁰ 系数）
  → Res_y(R,H) = P(x)          ← 一元
  → Sturm 计数 + 求根 → 逐 x 回代求 y → 逐 (x,y) 求 z → 回代三式
```

### 关键数学依据
| 环节 | 依据 |
| :-- | :-- |
| 结式降维 | `Res_y(f,g)` 的实根 ⇔ 原系统在该 x 上有公共 y 实根 |
| 完备性（二元） | Sturm 定理给出**精确**实根个数；每个 x 都产出通过回代的解 ⇒ 无缺口 |
| 重根处理 | 实根**个数**只由 square-free 部分 `R/gcd(R,R')` 决定 ⇒ 重根下 Sturm 仍可用 |
| 公共因子检测 | f、g 在 y 上有非常数公共因子 ⇔ 解集是**曲线**（非零维）⇒ 放弃，不把曲线上一点误报为「全部解」 |
| PRS 代替 Bareiss | PRS 的 last remainder 与 Sylvester 行列式只差**非零因子** ⇒ 根集相同；且**不需要精确整除** |

## 四、诚实边界（三态，严格区分「证不出」与「证为空」）

| 路径 | 能证什么 | 不能证什么 | 字段 |
| :-- | :-- | :-- | :-- |
| 二元 | 解全部正确 + **完备性有 Sturm 证明** | — | `s59Exact.completeness.proven = true` |
| 三元 | 解全部正确（三式回代） | **不宣称完备** | `s59Exact.completenessProven = false` + note |
| 无解（二元） | Sturm 计数 0 ⇒ **证明无解** | — | `provenEmpty: true` |

**三元为何不给完备性证明**：两次结式必然引入伪根（公共因子、无穷远根），虽已在回代时剔除，但 Sturm 数出的 x 根数**不能**直接充当三元解集的完备性证明。宁可少声明，不可虚假声明。

## 五、实现中踩到的 10 个坑（全部有独立验算，非手算）

| # | 症状 | 根因 | 修法 |
| :-- | :-- | :-- | :-- |
| 1 | `x²+y²=25` 与 `x+y=1` 被整条拒绝 | `cell()` 把矩阵元补齐到 `maxDegX+1`，Bareiss 乘法顶到 `maxLen` 误判「系数爆炸」 | 用紧凑 trim 形式 |
| 2 | 大量低次系统被误拒 | 次数上界写成 `nf·maxDx + ng·maxDx`（同一个 maxDx，系统性虚高） | 改为 `nf·deg_x g + ng·deg_x f` |
| 3 | `x⁴=1` 与 `x²+y²=5` **漏 4 解** | 要求「两方程都含 y」过严 | 一个含 y 即可；含 y 次数高者当 f |
| 4 | `x³=y, y³=x` **漏 3 解** | 主元打分「从高次按 1e-3 权压缩」让 1 次项压过 3 次项 ⇒ 中间量爆炸成 `NaN` | 改为「先比最高非零次数，同次数再比系数绝对值」 |
| 5 | `x⁴=1` 那题无完备性证明 | `Res = (x⁴−1)²` 有重根 ⇒ Sturm 因公因子失败 | square-free fallback：`R/gcd(R,R')` |
| 6 | 完备性对账误判「不完备」 | **量纲错**：Sturm 数 x 根数，解数是 (x,y) 对数 | 改为「不同 x 值数 ≥ Sturm 计数」 |
| 7 | `x²+y²=25` 被误判有公共因子 | 判据用「Res 次数 < 理论上界」，但**消元本身就会降次** | 改判**零维性**：多探针 x 值下算一元 gcd |
| 8 | 三元 `x²+y²+z²=1` 三式被整条拒绝 | Bareiss 的精确整除在二元系数域上不可用 | 改 **PRS**（伪余式链，只需乘减） |
| 9 | 三元 `x²+y²+z²=4, Σ=1, x=y` **漏 2 解** | 「第三式必须含 z」过严 | 不含 z 的方程本身即 (x,y) 约束，直接与 R 组成二元系统 |
| 10 | 三元 `cubic chain` **漏 9 解** | 主消元对象固定取 `eqs[0]`、`eqs[1]`；若两者都不含 z，`Res_z` 退化成乘积 | **必须挑【含 z 的方程】做主消元**；三个都不含 z ⇒ z 自由 ⇒ 放弃 |

### 附：多层多项式算术的「层数」坑（同一个根因，4 次）
三元实现需要 BQ（`(x,y)`，y 升幂/x 升幂）与 BT（三元，z 升幂/元素 BQ）两层。四次静默出错（不崩溃、只是答案错）：
1. `y` 的幂次混进 `z` 升幂层 ⇒ `x²+y²+z²−1` 的 z² 系数算成 `x⁴+1`；
2. `BQMul` 的 out 初值写成 `[[0]]`（多一层）⇒ 产出 `"00"` 字符串污染；
3. `BQNorm` 兜底零元写成 `[0]`（少一层）；
4. `BQDegY` 用 `BQIsZero`（**双重判零**）⇒ y 次数恒为 0 ⇒ 结式被误判退化。

> **铁律**：实现多层嵌套多项式算术，必须为每一层单独定义「零元 / 判零 / 拷贝 / 缩放 / 次数」五个操作，并逐层单测。混用相邻层的判零函数会**静默**给出错误次数。

## 六、fail-closed 契约

- 非二元/三元、含超越函数、含除法、次数超界 ⇒ **立即返回 null，零行为变更**（交回原采样/牛顿路径）；
- 公共因子（解集是曲线）⇒ 放弃，不把曲线上一点误报为「全部解」；
- 第三式不含 z 时**不拒绝**，改走 (x,y) 约束路线（修掉了漏 2 解的缺陷）；
- 每个解必须回代**全部原方程**，残差 > 1e-6 即丢弃；
- 解数超 `maxOut` ⇒ 如实标 `truncated` / `unconverged`，绝不静默丢解。
