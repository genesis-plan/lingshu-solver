## 三、托管端点计费

**仅限我们自运维的远程端点** `https://hongchenlingjing.com/mcp`。

| 项 | 值 |
|---|---|
| 单价 | **固定 ¥0.01 / 次**（每次 `solve` 一分钱）—— **不预充、无套餐、无其他档位、不设折扣** |
| 计费时机 | **仅在成功产出求解结果时扣费** |
| 不扣费 | 输入不合法、方程无法解析（响应 `diagnostics.inputError` 非空）、内部错误、余额不足 |
| 免费工具 | `initialize` / `tools/list` / `give_feedback` / 余额查询 / 价格查询 |
| **免费路径** | `solve` 入参加 `"honorPaid": true` ⇒ **免费放行**（不验证、不扣余额） |
| 凭证 | 请求头 `Authorization: Bearer <key>` 或 `x-api-key`（**不支持 URL 查询串传凭证**） |
| 注册 | **不需要**。凭证即身份（无用户名、无密码、不收邮箱手机号） |
| 个人信息 | **不收集、不存储**；建单时提交的联系方式与自由文本一律丢弃 |
| 入账 | **付款后自助入账**：调 `pay` 传 `{"orderId":"…","selfReportPaid":true}` ⇒ 立即入账、立即放行，**无需任何人工审核** |

### 3.1 为什么是"信任制"

服务端按**信任制**运转：愿意支持的付费，不愿意的照常使用（传 `honorPaid` 即可）。
理由很直接——同一个端点本来就提供了免费路径，**拦人不会增加收入，只会减少用量**；
把免费路径写在响应里，反而让"愿意付的人"更容易付。

**1 分/次是定价信号，不是硬门槛。** 本地版（`npx`）与网页版永久免费、不限次数、可离线。

### 3.2 我们自己的营收口径（诚实分栏，不虚报）

| 口径 | 含义 |
|---|---|
| `verifiedRevenueCents` | **真营收**：经对公流水核对过的金额 |
| `selfReportedCents` | 凭付款方**声明**入账的额度（`amountVerified:false`） |
| `honorClaims` / `selfReportClaims` | 免费放行与自助声明的**用量计数**，**不计入营收** |

**声明类额度绝不与真营收相加。** 相关计数在 `/health`、账本在 `/admin/ledger` 可见。

### 3.3 端点的其他接口

```bash

curl -X POST https://hongchenlingjing.com/pay/order \
      -H 'Content-Type: application/json' -d '{}'                           # 下单（每次恒 1 次 = 1 分）

```

## 八、常见问题

**Q：我只是自己用 / 教学用，要付费吗？**
不用。非商业使用免费（见第二节），网页版与本地 `npx` 形态永久免费、不限次数。

**Q：我在公司内部评估，算商业使用吗？**
年营收 ≤ 100 万元且仅内部评估、实例 ≤ 3 个，属免费范围；**一旦用于营利业务或对外提供能力，就需要商业授权。**

**Q：可以免费试用企业版能力吗？**
可以先在本地 `npx` 形态完整验证能力（免费、不限次数）；私有化交付与 SLA 属授权范围。

**Q：认证能保证结果一定正确吗？**
不能，也不这么宣称。认证表示"在给定模型与预算内，该解经区间验证、可复现"；
预算内未穷尽会诚实标 `truncated`。我们提供的是"可验证的部分盖章 + 不可验证的明说"。

**Q：你们会不会看我提交的方程？**
托管端点只记录订单号、凭证 SHA-256、余额/次数、时间戳与来源 IP，**不留存方程内容**；
需要数据不出域请用本地版或私有化部署。详见 [privacy.html](../privacy.html)。

**Q：私有化部署怎么交付？**
按合同交付部署包与配置说明，由你们在内网运行；计费开关默认关闭（自托管不会被我们收费）。

**Q：能改许可证吗？/ 早期版本是什么许可？**
`1.0.4` 起适用自有商业授权协议；`1.0.3` 及更早版本按其发布时的 Apache License 2.0 提供（历史事实，不可撤回，但不延伸至新版本）。见 [LICENSE](../LICENSE) 第九条与 [08 · 版本管理](08-版本管理.md)。
