# 灵数求解器 · 算子手册（suan1 – suan49）

> 本文档列出灵数求解器内核中注册的 **49 个算子（suan1 … suan49）**，按其在确定性求解流水线中的角色分组，并说明每个算子的作用。
> 数据来源：内核 `index.html` 中的 `_op(...)` 注册表（已实跑抽取，连续无缺号）。

---

## 1. 流水线总览

求解内核是一条 **「解析 → 护栏 → 矛盾证明 → 域收缩 → 代数闭式 → 数值兜底 → 全局搜索 → 后处理 → 输出」** 的确定性流水线。
任一分支在遇到证明无解或成功求解时提前返回；否则最终落入分支定界全局搜索（尽力而为、带 `truncated` 诚实标）。

```
setup/guard ──▶ prove(轻量矛盾) ──▶ contract(域收缩) ──▶ rewrite/solve(代数闭式)
                                                          │
                                                          ▼
                                              contract(区间/仿射收缩核心)
                                                          │
                                                          ▼
                              prove(单调/凸性剪枝) ──▶ analyze(几何拓扑) ──▶ sample(流形)
                                                          │
                                                          ▼
                              solve(数值迭代) ──▶ filter(后处理) ──▶ search(分支定界) ──▶ output
```

---

## 2. 标志说明

每个算子注册时带两个布尔标志：

| 标志 | 含义 |
|---|---|
| `contract = true` | 该算子会**收缩变量搜索域**（Domain contraction），是区间/仿射算术收窄解空间的核心机制。 |
| `sound = true` | 该算子的结论**可进入严格证明链**（不会引入伪根）；`sound = false` 表示其结论为启发式/数值性，仅用于剪枝或候选生成，不能当作证明。 |

## 4. 分层说明

### 层 0 · 解析与护栏（setup / guard）— suan1 – suan6
把用户输入转为标准代数结构，并完成**早筛**：变量数 >6 立即终止（suan3），白名单外危险算子立即拦截（suan4）。这是安全与规格的第一道闸门。

### 层 1 · 轻量矛盾证明（prove）— suan7、suan10、suan11
不收缩域，只做**快速无解证明**：区间前向传播即刻为空（suan7）、常量/赋值自相矛盾（suan10）、结构恒正/恒负（suan11）。三者 `sound=true`，结论可进严格证明链。

### 层 2 · 自动约束与基础收缩（contract）— suan9、suan12
从方程结构自动推导隐含定义域（根号内非负、分母非零）并收缩（suan9），以及压缩映射基础区间缩集（suan12）。均 `contract=true, sound=true`。

### 层 3 · 代数闭式求解（rewrite / solve，强顺序依赖）— suan15 – suan23
该层有**强顺序依赖：化简 → 消元 → 回代**，不可乱序、不可进不动点。
- 化简：suan15（微积分化简）、suan16（兼容分支）、suan23（分式变量替换）
- 消元/求解：suan17（高斯消元）、suan19（显式代入消元）、suan20（有理根枚举）、suan22（超越方程牛顿）
- 结构分析：suan18（图论拆子系统）、suan21（欠定标记）

### 层 4 · 区间/仿射收缩核心（contract）— suan24 – suan34
确定性求解的**主力收缩栈**，全部 `contract=true`：
- suan25 区间算术值域收缩（最便宜，层内反复压到不动点）
- suan26 奇偶对称压缩、suan27 HC4-Revise、suan28 项一致性反演
- suan29–suan30 单调/凸性严格剪枝（sound=true）
- suan31–suan32 Box-Consistency（BC3 / 2B·3B）
- suan33 Hansen-Sengupta 区间 Gauss-Seidel、suan34 LP Narrowing
- suan24 多项式全域根收割（contract=true，但依赖数值求根完备性，故 sound=false）

### 层 5 · 单调/凸性证明剪枝（prove）— suan29、suan30、suan35
用导数/中值定理/凸性做**严格剪枝**（sound=true），把不含解的子区间从搜索空间剔除。

### 层 6 · 几何拓扑分析（analyze）— suan8、suan13、suan14、suan36、suan37
只写性质（manifoldInfo / startPoints），**不收缩域**：极限预判、特征标记、流形奇点标记、雅可比秩引导投影、流形分类。

### 层 7 · 采样与流形（sample）— suan38、suan39
固定规则均匀采样与零空间流形投影校准，为数值层提供初值。

### 层 8 · 数值迭代求解（solve）— suan40、suan41、suan48
Armijo 线搜索牛顿（suan40）、区间牛顿兜底求精（suan41，给出含根区间且不漏）、不等式系统专用求解（suan48）。

### 层 9 · 后处理过滤（filter）— suan42 – suan46
残差过滤（suan42）、精度标准化（suan43）、全局约束复核剔伪根（suan44）、物理限位过滤（suan45）、解集去重合并（suan46）。

### 层 10 · 兜底搜索与输出（search / output）— suan47、suan49
分支定界递归二分（suan47）做**尽力而为的全局穷尽**（预算耗尽则带 `truncated` 诚实标）；收敛判定与结果输出（suan49）。

## 5. 备注

- 内核中有一处导航注释称「suan7 未实现」——**该注释已过时**。实跑抽取确认 suan1–suan49 连续注册、全部实现。
- `contract` 算子共 16 个（suan9,12,24–34），是域收缩的主力；`sound` 算子共 13 个（suan7,9–12,25–30,33,34,35），其结论可进入严格证明链。
- 算子注册顺序敏感（尤其 suan4 须在 D0 初始化后立即执行），新增算子不得破坏既有顺序契约。
