# 灵数求解器 · EVM / 智能合约确定性求解子集

> 本页所有数值均为实跑输出（`tier=proven`，经 Krawczyk 区间认证）。

## 这个子集是什么

链上有大量"算错就亏钱"的**实数方程**：兑换产出、清算价格、无常损失、路由拆分、套利规模。
它们的共同特征是——低维（≤6 变量）、非线性（乘积、分式、指数）、要求可复现。

这些正好落在灵数求解器的能力圈内：不给初值、不猜、不编，解出来带认证半径。

**不属于这个子集的（我们不冒充）**：整数溢出、符号执行、形式化验证、gas 精确建模、MEV 竞价策略。
这些请用 Slither / Halmos / Certora / Foundry。我们是它们旁边那个"负责把数算准"的后端。

## 用例 1 · Uniswap V2 兑换产出（含 0.3% 手续费）

池：100 ETH / 200,000 USDC，投入 10 ETH，手续费后有效投入 9.97，求产出 b。

```json
{"equations":["(100+9.97)*(200000-b)-100*200000 = 0"],"variables":["b"],"domain":{"b":[0,200000]}}
```

→ **b = 18,132.217878 USDC**（21 ms，1 解，proven）

闭式对照：`b = 200000 - 20000000/109.97 = 18132.2179` ✓

## 用例 2 · 无常损失反解价格比

LP 相对 HODL 的损失 `IL = 2√r/(1+r) − 1`，求 IL = −2% 时的价格变动比 r。

```json
{"equations":["2*sqrt(r)/(1+r)-1+0.02 = 0"],"variables":["r"],"domain":{"r":[0.01,100]}}
```

→ **r = 0.668060 或 1.496871**（16 ms，2 解，proven）

闭式对照：令 u=√r，`0.98u² − 2u + 0.98 = 0` → `u = (2±√0.1584)/1.96` → `r = 0.66806, 1.49687` ✓
（两解互为倒数：跌 33.2% 或涨 49.7%，LP 亏损相同。）

## 用例 3 · 双池最优拆单（路由）

卖 100 ETH。A 池 500 ETH / 1,500,000 USDC，B 池 300 ETH / 930,000 USDC。
最优分配的一阶条件：**两边边际产出相等**（令 x 进 A、y 进 B）。

```json
{"equations":[
  "1495500000*500000/(500000+997*x)^2 - 927210000*300000/(300000+997*y)^2 = 0",
  "x+y-100 = 0"
],"variables":["x","y"],"domain":{"x":[0.001,99.999],"y":[0.001,99.999]}}
```

→ **x = 59.0254（A 池），y = 40.9746（B 池）**（33 ms，proven）

| 方案 | 产出 USDC |
|---|---|
| 全部卖 A 池 | 249,374.69 |
| 全部卖 B 池 | 231,976.48 |
| **最优拆单** | **269,416.42** |

拆单比最优单池**多 20,041.73 USDC（+8.04%）**。

一阶条件验算：两边边际产出均为 2394.3 ✓
（注：A 池容量大因而多吃 59 ETH，但 B 池承担的相对冲击更大 —— 13.7% vs 11.8%，这就是最优的含义。）

## 用例 4 · 跨池搬砖最优投入量（套利）

A 池 100 ETH / 200,000 USDC（价 2000），B 池 150 ETH / 310,000 USDC（价 2066.7），存在价差。
用 U 个 USDC 在 A 买 e 个 ETH，再到 B 卖出得 V 个 USDC，最大化 `V − U`。

三变量联立：A 池不变式 + B 池不变式 + 无套利一阶条件（`dV/dU = 1`）。

```json
{"equations":[
  "(100-e)*(200000+0.997*U)-20000000 = 0",
  "(150+0.997*e)*(310000-V)-46500000 = 0",
  "0.997*(310000-V)/(150+0.997*e)-(200000+0.997*U)/(0.997*(100-e)) = 0"
],"variables":["U","e","V"],"domain":{"U":[1,200000],"e":[0.001,99],"V":[1,310000]}}
```

→ **U = 1,624.47 USDC → e = 0.8033 ETH → V = 1,646.37 USDC**，净利 **21.90 USDC**（547 ms，proven）

## 用例 5 · 清算价格（Aave / Compound 型）

抵押 10 ETH，债务 12,000 USDC，清算阈值 0.825，求触发清算的 ETH 价格。

```json
{"equations":["10*P*0.825-12000 = 0"],"variables":["P"],"domain":{"P":[1,10000]}}
```

→ **P = 1454.545455 USDC/ETH**（1 ms，proven）

## 使用注意（实测踩到）

1. **变量名不要纯双字母**。`xy`、`ab`、`oa` 会被解析器当成两个变量相乘（如 `xy` → `x·y`），导致声明的变量与方程变量不匹配而报"无解"。改用 `x1`、`out1`、`c0` 这类**字母+数字**形式即正常。
   - 实测对照：`xy - 249374.7 = 0` → 无解；`out1 - 249374.7 = 0` → 正常解出。
2. **大数量级要显式给域**。链上数值常在 1e5–1e8 量级，超出默认搜索域 ±1e6，不给 `domain` 会直接空集。
3. **拆单/套利类问题用一阶条件建模**，求解器解的是方程组，不会替你做优化——把 `d(profit)/dx = 0` 写成方程交给它。
4. 超定系统（方程数 > 变量数）目前表现不稳定（实测 3 方程 2 变量的几何定位返回 0 解），建议先化为**适定**方程组再求解。
