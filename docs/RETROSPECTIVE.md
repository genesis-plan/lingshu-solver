## 0. 一句话定位

灵数求解器是一个**纯前端的确定性实数方程组求解引擎**（≤6 变量、默认搜索域 ±1e6、输出固定 6 位小数），面向个人/会计/AI Agent 三类使用者；对 AI Agent 额外提供 MCP 服务。数学正确性优先，对外**绝不承诺"保证不漏解"**，只承诺"已验证解数学保真 + 全局穷尽尽力而为（truncated 诚实标）"。

## 2. 关键修复与踩坑（按严重度）

### 2.1 P0 · 只传部分变量 `domain` 会崩溃（已修并上线）
- **现象**：`x1=12,x2=5,x1/x2-x3=0` 配 `{"x3":[0,10]}` → `Cannot read properties of undefined (reading '0')`。
- **根因**：① D0 初始化对未指定变量 `continue` 跳过 → 该变量无 `{min,max}`；② `_globalBranchCertify` 的 `mkBox` 按数组格式域取 `[0]/[1]`，却直接传原始 `userDomain` → 缺失变量 `undefined[0]` 崩溃。
- **修法**：缺失变量补默认 ±1e6；调用前构造"补全 + 统一数组格式"的域，非法则跳过全局分支。已锁进 `verify_core.js` 第 10 组断言。

### 2.2 严重 · issue A：周期/高频方程静默漏支（已修并上线）
- **现象**：`cos(x)=0.5` 在 `[0,2π]` 只给 1 根（应 2）、`[0,20]` 给 4（应 7）；`sin(100x)=0` 给 2（应 32）。无 `truncated` 标 → **静默假阴性**。
- **根因**："阶段 3.5 提前多起点牛顿"短路只返回 1 个基解。
- **修法**：仅"纯净单变量输入"清空牛顿短路标志，交 `suan22` 周期感知自适应扫描补全全根；多变量方阵与消元后"伪单变量"保持短路，避免丢失自由参数采样。
- **诚实提示（非缺陷）**：单变量周期方程在默认全域 ±1e6 真根可达数十万（如 `sin(x)=0.5` ≈ 63 万），诚实穷举耗时分钟级；需局部根请显式传 `domain`。

### 2.3 中 · 豆包"打竖"粘贴（换行打断隐式乘法，已修）
- **根因两层**：① Unicode 符号 `−`(U+2212)/`·`(U+00B7)/`≠`(U+2260) 未归一化；② 豆包每字符独立成行，换行打断隐式乘法规则。
- **修法**：符号归一化 + 去除单条方程内换行；网页在"整段仅一个 `=` 却跨多行"时自动合并。
- **验证**：竖排 `4(x−2)+3=2x+7`→x=6；远程 MCP 竖排方程解出 x=6 certified。

### 2.4 中 · 希腊变量名的域键失配（已修）
- **现象**：`sin(theta)=0.5` 配 `{theta:[0,2π]}` 挂起 >4 分钟。
- **根因**：变量名归一化阶段把 `theta`→`θ`，但域对象键未同步映射 → 域被静默丢弃 → 退回 ±1e6 触发 issue A 后的全域穷举。
- **修法**：归一化路径对域键按同一规则映射后再递归求解。**永久测试必须带域**，否则会挂。

### 2.5 COS 同步间歇性 403（根因误判，已澄清）
- **误判**：曾以为"COS 密钥轮换 / DNS 轮询"导致签名偶发失败。
- **真相**：是**手搓 COS v5 签名脚本的算法 bug**（非密钥问题）。改用官方 `cos-nodejs-sdk-v5` → **一次成功无 403**。
- **经验**：COS 同步一律用官方 SDK，不要再手搓签名（见 §5）。

## 5. 可复用的工程经验（给后续维护者）

1. **三份文件一致性**：线上改核心必须同时传 `/var/www/lingshu/index.html` 与 `/opt/lingshu/index.html`（核心由 http-mcp-server.js 读取后者），并同步 COS 镜像与 GitHub。改 MCP 行为只动 `http-mcp-server.js`，改 `mcp-server.js` 线上无效。
2. **COS 同步用官方 SDK**：`NODE_PATH` 指向受管 node 的 `workspace/node_modules`，`require('cos-nodejs-sdk-v5')`；手搓签名必踩 403。
3. **git 推送绕行**：沙箱内直推常因代理 502 失败 → 用 `git -c http.sslBackend=openssl -c http.version=HTTP/1.1 push`；仍失败再走 GitHub contents API（每文件一步、显式 `Content-Length`、回读校验、路径不可二次 quote）。
4. **测试即护栏**：每次修复都补永久回归用例（issue A / paste / 部分域 / 合规）；`reset --hard` 前先 `git rev-parse origin/master` 核对引用新鲜度（fetch 可能静默失败）。
5. **诚实优先于营销**：所有"通过"以测试为据；所有"缺陷"如实标注；不夸大量级、不虚构行为（专利/对外说明须贴近真实实现）。
6. **变量识别设计成立**：变量框留空时从方程 AST 提取并回填；用户以为"没识别"多为解析失败表象，先查归一化而非识别逻辑。
