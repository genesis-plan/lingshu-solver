## 3. 主要工作流与决策

### 3.1 求解内核修复（数学正确优先）
- **issue A（严重）**：周期/高频方程经"提前多起点牛顿"短路只返 1 基解且不标 `truncated` → 静默漏支。`cos(x)=0.5 [0,2π]` 仅 1 解（应 2）。修法：纯净单变量输入才清空短路、交 `suan22` 周期感知扫描补全；多变量/伪单变量保持短路防丢自由参数。**诚实提示**：单变量周期方程默认全域 ±1e6 真根可达数十万，穷举分钟级——要局部根请显式传 `domain`。
- **豆包"打竖"粘贴（中）**：根因两层——Unicode 符号 `−/·/≠` 未归一化 + 换行打断隐式乘法。修法：符号归一化 + 去方程内换行 + 网页自动合并"单 `=` 跨多行"。
- **P0 部分域崩溃**：只传部分变量 `domain` 抛 `undefined[0]`。修法：缺失变量补 ±1e6、统一数组格式域。
- **希腊变量名域键失配（中）**：`theta`→`θ` 但域键未同步映射 → 域被静默丢弃 → 退回 ±1e6 触发 issue A 穷举挂起。修法：域键同规则映射。**永久测试必须带域**。

### 3.2 安全与合规（等保自查）
- 网页本就零数据上行（纯前端、无上传/Cookie/第三方）；MCP 日志只记元数据不含方程。
- 加固：XSS 转义、MCP 请求体 256KB(413)/限速 120 次分(429)/会话 TTL/日志轮转/反馈脱敏、nginx 安全头（CSP/X-Frame-Options/nosniff/referrer/server_tokens off）。
- **关键决策（用户拍板）**：手机号/证件号/银行卡/邮箱**不再拦截**，按普通数学常量放行——"我们还是求解器"。门禁精简为两条：非数学自然语言拒收 + 100KB 上限。

### 3.3 部署与多端一致性（最易踩坑的一段）
- **三份文件一致性**：线上改核心必须同时传 `/var/www/lingshu/index.html` 与 `/opt/lingshu/index.html`（核心由 `http-mcp-server.js` 读后者）；改 MCP 行为只动 `http-mcp-server.js`，改 `mcp-server.js` 线上无效。并同步 COS 镜像与 GitHub。
- **证书自动续期此前完全没配** → 加 root cron `certbot renew --quiet --deploy-hook "systemctl reload nginx"`（certbot shebang 是 `python3 -s`，续期须用 `python3 /usr/bin/certbot` 绕过）。
- **www 缺口闭环**：`www.hongchenlingjing.com` 的 A 记录其实已存在（早前本地 dig 误报空），`certbot --expand` 把 SAN 扩入两域名，外部实测 `https://www.*` 200 且证书有效。
- **COS 同步根因澄清**：曾误判"密钥轮换/DNS 轮询"导致 403。**真相是手搓 COS v5 签名算法的 bug**，改用官方 `cos-nodejs-sdk-v5` 一次成功。

## 4. 关键战略决策与转向（值得记下来的"为什么"）

1. **从大愿景收口到实体产品**：通用大脑是长期叙事，但先交付一个数学正确、可演示、可分发的具体东西。求解器是这个收口。
2. **主交付形态 = MCP + npm，网页 = demo**：域名为管道非产品。
3. **定位回归纯求解器**：曾因"等保"想拦手机号/证件号，用户一句"我们还是求解器"把方向拉回——数字就是数学常量，不该拦。
4. **诚实优先于营销**：不夸大量级、不虚构行为、不承诺"不漏解"。专利/对外说明须贴近真实实现。
5. **被动获客**：不主动推广，等真实使用信号再投入（双曲反三角、Bug B 等皆"有信号再做"）。
6. **AI 不替用户定方向**：方向由用户拍板；AI 在执行层自主、敢独立判断甚至反对，但不替用户选战略。

## 5. 踩过的坑（工程 + 认知）

**工程坑**
- COS 手搓签名 → 403（用官方 SDK）。
- `reset --hard` 前没核对 `origin/master` 新鲜度（fetch 静默失败）→ 误删本地文档；恢复靠 contents API 逐文件拉回。
- autocrlf 下 `git diff` 报全文件伪 diff，判断真实差异须 `--ignore-cr-at-eol`。
- 沙箱 git 推 `github.com:443` 常代理 502 → `git -c http.sslBackend=openssl -c http.version=HTTP/1.1 push`；仍失败走 contents API（显式 Content-Length、路径不可二次 quote、回读校验）。
- GitHub contents API DELETE 带 chunked body 被忽略 → 须显式 `Content-Length`。
- 本地 grep 误报"旧版"：用了非真实修复写法（如 `Array.isArray(dom[v])`）当判据，实为误判；以 md5/字节比对为准。
- 无域周期方程用例会挂 → 永久测试必须带域。

**认知坑（更贵的那种）**
- 把"用户以为没识别变量"当成识别逻辑缺陷，实际是解析/归一化失败表象——先查归一化。
- 把"COS 间歇性 403"当成基础设施问题（密钥轮换），浪费多轮诊断，实为自写签名错。
- 把"本地 dig 空"当成"www 没配 DNS"，实为本地解析器盲区——以服务器/公共解析器为准。
